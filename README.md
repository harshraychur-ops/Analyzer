📊 Project2 – Excel Data Analysis & Visualization
📁 Overview

This project contains an Excel workbook demonstrating data analysis, statistical techniques, and visualizations using Microsoft Excel. The file showcases practical use of formulas, charts, pivot tables, and analytical tools commonly used in business and data analysis.

📂 File Details

File Name: Project2.xlsx

Tool Used: Microsoft Excel

Purpose: Data analysis, reporting, and visualization
